OPENDART · 금융감독원 전자공시 Open API

DART 데이터로 무엇을 만들 수 있을까

OpenDART는 금융감독원 전자공시시스템(DART)의 공시·재무·지분 데이터를 무료 API로 제공합니다. API 키 하나로 상장·비상장 기업의 공시 목록, 재무제표, 배당, 임원 보수, 대주주 지분 변동까지 가져올 수 있어요. 아래는 이 데이터로 만들 수 있는 프로젝트 아이디어와 시작 방법입니다.

보고서 코드(reprt_code): 11013 1분기 · 11012 반기 · 11014 3분기 · 11011 사업보고서. 모든 요청에 crtfc_key(인증키)가 필요합니다.

5분 만에 첫 호출

  1. opendart.fss.or.kr 회원가입 → 인증키 신청 → 메일로 40자리 키 수신
  2. corpCode.xml을 받아 회사명 → corp_code(8자리) 매핑 테이블 만들기
  3. 원하는 API에 corp_code, bsns_year, reprt_code를 넣어 호출

예시 — 삼성전자(00126380) 2024년 사업보고서 주요 계정 조회:

import requests

API_KEY = "여기에_인증키"
url = "https://opendart.fss.or.kr/api/fnlttSinglAcnt.json"
params = {
    "crtfc_key": API_KEY,
    "corp_code": "00126380",   # 삼성전자
    "bsns_year": "2024",
    "reprt_code": "11011",     # 사업보고서
}
data = requests.get(url, params=params).json()

for row in data.get("list", []):
    if row["fs_div"] == "CFS" and row["account_nm"] in ("매출액", "영업이익", "당기순이익"):
        print(row["account_nm"], row["thstrm_amount"])

💡 파이썬에서는 OpenDartReader, dart-fss 같은 라이브러리를 쓰면 회사명만으로도 조회할 수 있어 훨씬 편합니다.

만들 때 알아두면 좋은 것

호출 한도 관리

일 약 2만 회 제한이 있어요. 재무 데이터는 분기마다만 바뀌니 SQLite 등에 캐싱해 두고 공시 목록만 주기적으로 조회하세요.

계정명이 회사마다 달라요

"매출액" / "수익(매출액)" / "영업수익"처럼 표기가 다릅니다. 여러 회사를 비교할 땐 account_id(XBRL 표준 계정)로 매칭하는 게 안전해요.

연결 vs 별도

fs_div가 CFS(연결)인지 OFS(별도)인지 꼭 구분하세요. 지주사는 둘의 차이가 매우 큽니다.

실시간은 아니에요

공시 반영에 수 분 지연이 있을 수 있어요. 초단위 트레이딩보다는 알림·분석 용도에 적합합니다.
