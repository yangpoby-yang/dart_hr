# DART HR 비교

OpenDART 사업보고서로 두 기업·한 사업연도의 인사 지표를 비교하고, 서버가 계산한 값만으로 AI HR 브리핑과 후속 대화를 제공하는 Next.js 앱입니다.

- **사업연도말 직원 수**: 직원현황(empSttus) 합계(sm). 회사 합계 행 → 성별합계 남+여 → 완전한 부문 상세 합 순으로 기준을 정하고, 기준끼리 충돌하면 보류합니다. 성별합계와 부문 상세는 섞어 더하지 않습니다.
- **기말 인원당 급여총액 · 계산값(공시 1인평균 아님)**: 연간급여총액 ÷ 검증된 사업연도말 직원 수.
- **인당 매출 · 계산값**: 같은 사업연도 별도(OFS) 손익계산서 매출액 ÷ 직원 수. 연결(CFS)로 대체하지 않습니다.
- **남녀 공시 1인평균급여**: 공시값 그대로. 남녀 값을 평균·가중해 회사 평균을 만들지 않습니다.

비고(rm)의 단위 표기를 따르고 표기가 섞이면 원화 값을 보류합니다. 결산기준일이 사업연도와 다르거나, 계산에 쓴 행의 합계가 정규직+기간제와 맞지 않으면 직원 범위 미확인으로 보류합니다.

## 실행

```bash
npm install
cp .env.example .env   # OPENDART_API_KEY, OPENAI_API_KEY, OPENAI_MODEL 입력
npm run dev            # http://localhost:3000
```

키가 없어도 "합성 예시" 모드로 계산 규칙과 화면 흐름을 확인할 수 있습니다.

## 검사

```bash
npm test                                               # 합성 규칙 테스트
npm run step0 -- 2024,2025 삼성전자 SK하이닉스            # 실제 empSttus 원본 행 · 분류 · 사용/제외 이유 (step0/에 저장)
npx tsx scripts/verify-live.mts 2024,2025 00126380 00164779   # 독립 재계산 ↔ 화면 값 ↔ AI 전달값 대조 (앱 실행 중)
```

## 구조

| 경로 | 역할 |
|---|---|
| `lib/emp.ts` | 행 분류, 단위 판정, 인원·급여총액 교차검증, 범위 확인, 행별 사용·제외 이유 |
| `lib/revenue.ts` | 별도(OFS) 매출 추출과 인당 매출 |
| `lib/compare.ts` | 두 기업 비교, 서버 격차·격차율 |
| `lib/ai.ts` | AI에 전달할 화이트리스트 맥락, 브리핑·후속 대화 |
| `app/` | 화면과 API 라우트 |
| `lib/synthetic.ts` | 합성 예시 데이터(실제 기업 아님) |
